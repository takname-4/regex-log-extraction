# 정규표현식을 활용한 축제 운영 로그 데이터 추출

## 1. 프로젝트 소개
전주대학교 대동제 및 밤샘 해커톤 통합 운영 로그에서 정규표현식을 사용해 필요한 정보를 추출하는 파이썬 프로그램입니다.

## 2. 사용한 기술
- Python
- `re` 모듈: 정규표현식으로 필요한 문자열 찾기
- `open()`, `read()`: 텍스트 파일 읽기
- 반복문과 리스트: 추출한 결과 출력 및 매출 합산

## 3. 주요 기능
1. 올바른 형식의 이메일 주소 추출 (손상된 `hyunwoo@.ac.kr` 제외)
2. 010으로 시작하고 중간·끝 번호가 각각 4자리인 휴대폰 번호 추출
3. 202로 시작하는 9자리 학번과 학과명을 튜플로 추출
4. GitHub 저장소 주소와 2026년 쿠폰 코드 추출
5. 각 부스의 `매출:` 뒤 금액을 추출하고 전체 매출 합산

## 4. 실행 방법
파이썬 파일과 로그 텍스트 파일을 같은 폴더에 저장한 뒤 터미널에서 실행합니다.

```bash
python regex_log_extraction_simple.py
```

## 5. 실행 결과
제공된 로그 파일 기준 결과입니다.

- 이메일 주소: 5개
- 휴대폰 번호: 4개
- 학번 및 학과: 3개
- GitHub 저장소 주소: 3개
- 2026년 쿠폰 코드: 3개
- 부스별 매출: 4개
- 전체 매출 합계: **6,290,500원**

## 6. 파일 구성
- `regex_log_extraction_simple.py`: 정규표현식 데이터 추출 프로그램
- `07-02. 전주대 대동제 및 해커톤 통합운영 데이터 로그.txt`: 분석 대상 로그 파일
- `README.md`: 프로젝트 설명 및 실행 방법
